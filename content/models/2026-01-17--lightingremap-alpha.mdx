This LoRA targets a surprisingly practical workflow: you “paint in” lighting direction and mood by placing solid color blocks near the edge of an image (think: a blue block for a cold key light, an orange block for sunset fill), then let the model relight the scene and remove the blocks in the output. It’s a nice middle ground between fully manual post-processing and prompt-only lighting requests that often drift.

It’s designed for Qwen Image Edit (the `Qwen/Qwen-Image-Edit-2511` family) and the author shows it in a ComfyUI-style pipeline. The repo also calls out that this is an alpha release: in some cases the blocks may not be fully erased, and complex backgrounds can cause odd transitions. Still, if you want a fast way to iterate on “where is the light coming from?” without doing a full lighting-grade, this is an interesting knob to try.
